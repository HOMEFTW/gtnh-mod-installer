# GTNH 私货安装器

一个带 GUI 界面的应用程序，用于为 [GTNH（GregTech New Horizons）](https://gtnh.huijiwiki.com/wiki/%E9%A6%96%E9%A1%B5) Minecraft 整合包安装额外的模组、脚本、配置文件、字体和资源包。支持客户端和服务端分别管理。

## 功能特性

- **多类型资源管理** — 模组、脚本、配置、字体、资源包五大类资源，分类标签页展示
- **客户端/服务端分离** — 独立跟踪安装状态，分别备份还原
- **灵活的安装方式** — 双端安装、仅客户端、仅服务端可选
- **智能安装规则** — 模组按 `server_required` 字段决定服务端安装；脚本/配置始终双端；字体/资源包仅客户端
- **配置递归合并** — 配置文件安装时合并复制而非覆盖，保留客户端原有文件
- **字体双目录安装** — 自动复制到 `fonts/` 和 `fontfiles/` 两个目录
- **备份/还原** — 支持客户端备份、服务端备份、完整备份，还原时自动恢复空目录
- **安装清单 (.hflist)** — 生成安装清单分享给他人，支持菜单加载、拖放文件、Ctrl+V 粘贴路径
- **资源编辑器** — 双击或右键编辑资源元数据，修改文件名同步重命名文件本体
- **版本管理** — 支持多个 GTNH 版本（如 2.7.X、2.8.X），动态切换
