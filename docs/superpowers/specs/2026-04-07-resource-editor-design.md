# 资源编辑器设计文档

## 概述

为 GTNH 私货安装器添加一个资源元数据编辑器，允许用户通过 GUI 编辑 `resources.json` 中的资源信息。

## 文件结构

```
gui/
├── dialogs.py          # 现有对话框（不变）
├── resource_editor.py  # 新增：ResourceEditorDialog 类
├── main_window.py      # 修改：添加编辑器入口
└── widgets.py          # 修改：添加双击/右键回调
```

### 组件说明

- **顶部**：版本选择下拉框，切换要编辑的 GTNH 版本
- **左侧面板**：
  - 资源类型下拉框（模组/脚本/配置/字体/资源包）
  - 文件列表（Listbox），带状态标记（☑ 有元数据 / ☐ 无元数据）
  - "添加新资源"按钮
- **右侧面板**：
  - ID 输入框（必填）
  - 文件名输入框（必填）
  - 显示名称输入框
  - 说明文本框（多行）
  - 服务端需要安装复选框
  - 操作按钮：保存、删除、取消

## 数据流程

### 加载流程

1. 打开编辑器时，读取 `Addcontent/{版本}/resources.json`
2. 扫描 `Addcontent/{版本}/{类型}/` 目录获取实际文件列表
3. 合并显示：
   - 已有元数据的文件显示 ☑
   - 无元数据的文件显示 ☐

### 保存流程

1. 校验必填字段（ID、文件名）
2. 检查 ID 是否重复（编辑现有除外）
3. 更新内存中的 resources 数据
4. 写入 `Addcontent/{版本}/resources.json`
5. 刷新左侧列表状态

### 添加新资源

1. 点击"添加新资源"按钮
2. 弹出输入对话框，输入文件名
3. 在列表中添加新条目并自动选中
4. 自动生成 ID（基于文件名）

### 删除元数据

1. 从 resources 数据中移除该条目
2. 实际文件不删除
3. 刷新列表状态

## 主窗口集成

### 打开方式

1. **编辑按钮**：在操作区添加"编辑资源"按钮
2. **右键菜单**：资源列表右键菜单添加"编辑此资源"
3. **双击**：双击资源列表行打开编辑器并选中该资源

## 错误处理

| 情况 | 处理方式 |
|------|----------|
| resources.json 不存在 | 自动创建空结构 |
| resources.json 格式错误 | 提示用户，提供"重置为空"选项 |
| ID 重复 | 保存时检查，提示覆盖确认 |
| 必填字段为空 | 校验并提示 |
| 版本目录不存在 | 提示"请先创建版本目录" |

## resources.json 数据结构

```json
{
  "mods": [
    {
      "id": "mod-id",
      "name": "显示名称",
      "filename": "文件名.jar",
      "description": "说明文字",
      "server_required": true
    }
  ],
  "scripts": [],
  "configs": [],
  "fonts": [],
  "resourcepacks": []
}
```
